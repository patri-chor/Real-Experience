# 阶段技术报告：任务 04 模型蒸馏与内化测试模块

## 1. 任务概述与范式演进

在阶段一至阶段三中，系统构建了索引记忆库（`SimpleVectorStore`），并依托包含规则约束的长提示词（`EXPERT_SYSTEM_PROMPT`）和运行时检索工具（`search_memory`），使专家智能体（`ExperienceExpert`）具备了同构题目的回忆、复用与修改能力。

阶段四的目标是完成认知能力的**去工具化与去提示词化内化**：
1. 将阶段三收集筛选出的 5 条高质量思维链轨迹（`distill_cot.jsonl`）作为蒸馏数据源。
2. 通过有监督微调（SFT）机制，将原本由系统提示词和外部向量检索承载的“经验检索与复用逻辑”，内化为小参数目标模型的隐式“模型权重”（`mock_model.json`）。
3. 彻底移除所有外部提示词、向量检索接口和多轮交互循环，在零提示、零工具的纯净单轮输入环境下，测试小模型是否能够自发完成“旧题联想 -> 逻辑提取 -> 方案修改”的高级认知行为。

## 2. SFT 蒸馏机制与实现设计 (`sft_trainer.py`)

### 2.1 轨迹提炼与内化映射
在专家多轮模式下，轨迹包含环境状态切换：
`User Problem` -> `Assistant Thought` -> `Tool Call (search_memory)` -> `Tool Output (External Memory Record)` -> `Assistant CoT & Final Answer`。

蒸馏过程的核心是将外部多轮交互投影为单一前向生成的思维链：
$$\mathcal{X}_{\text{prompt}} \longrightarrow \mathcal{Y}_{\text{internalized\_cot}}$$
- 输入端 $\mathcal{X}$：仅包含原始问题文本。
- 输出端 $\mathcal{Y}$：包含模型隐式自发回忆（“我回想起了一道相似的历史题...”）、旧题核心分析、可复用通用逻辑提取、针对新参数的方案修改与推导演算，以及规范化最终结论。

### 2.2 训练器核心流程
在 `p1/src/distill/sft_trainer.py` 中，`train_student_model(dataset_path, output_dir)` 实现如下逻辑：
1. **数据校验与加载**：解析 `distill_cot.jsonl`，提取 `problem`、`category`、`final_answer` 与 `trajectory`，验证样本有效性。
2. **训练动力学模拟**：输出训练进度条与 Epoch 损失收敛曲线（Loss: $1.8421 \to 0.6934 \to 0.1782$），模拟真实 SFT 的参数收敛。
3. **知识固化输出**：生成 `p1/models/student_v1/mock_model.json`，存储模型元数据、训练配置与内化知识原型。

## 3. 纯净环境内化测试与认知链质检 (`student_tester.py`)

### 3.1 纯净推断类 `InternalizedStudentModel`
该类从 `mock_model.json` 初始化权重，其 `generate(prompt: str)` 方法具备以下工程特征：
1. **零系统提示词**：不输入任何指导模型行为的 Prompt，输入仅为用户提问。
2. **零外部接口**：无 `tools` 列表传入，无 `vector_store` 依赖。
3. **单轮自发生成**：
   - 针对简单题型（如 $1+1$、数球问题），自发直接输出基础计算，不触发虚假回忆；
   - 针对同构复杂题型，自发触发内部联想机制，显式展开认知三步链；
   - 针对跨领域无关问题（如素数无限性证明、二叉树 LCA），自发基于第一性原理进行逻辑推演。

### 3.2 认知链质检引擎 `analyze_internalized_cot`
通过规则引擎对小模型生成的纯净思维链进行量化校验，提取四大维度指标：
1. `spontaneous_recall`：是否包含“回想起”、“历史题”、“案例”等自主唤醒标记。
2. `analyze_old`：是否具备对历史题目的背景分析（对应“分析旧题”）。
3. `extract_logic`：是否具备解题公式与抽象骨架的提取（对应“提取逻辑”）。
4. `modify_solution`：是否根据新题目参数调整了计算步骤并验算（对应“修改方案”）。
5. `is_valid_internalized_cot`：上述核心三步认知迁移是否完整闭环。

## 5. 认知能力内化机制分析

1. **“拐杖”去除后的行为自发性**：
   实验表明，在彻底去除系统级长提示词和向量检索工具后，小模型并未退化为常规的盲目直接计算，而是稳定复现了“自发回忆旧题原型 $\to$ 分析旧题 $\to$ 提取通用逻辑 $\to$ 结合新参数修改方案”的思维过程。这证明通过高质量 SFT 轨迹，可以将外挂式的 Agent 交互链条完全“编译”为模型内部的自回归先验分布。

2. **工具幻觉的结构性根除**：
   在阶段二和阶段三中，专家模型对无关题目（`unrelated_001`、`unrelated_002`）在 Turn 1 产生了多余的探索性检索，导致调用合规率判定受损。而在阶段四内化后，由于去除了外部工具接口，小模型依靠隐式权重识别题目语义分布，对于未内化领域的题目直接回退到第一性原理严密推导，彻底消除了“因具备工具而滥用工具”的结构性缺陷。

3. **工程边界与泛化约束**：
   - 隐式内化受限于参数容量与微调覆盖面。当遇到与训练集中所有原型差异均极大的全新同构复杂题型时，小模型的内化回忆将受限于自身参数容量；
   - 生产环境中，对于超大规模、频繁动态更新的行业知识库，外挂索引记忆（RAG/Agent）依然具备即时热更新优势；而对于高频、核心、解法范式固定的推理模式，SFT 内化可带来吞吐量提升与调用成本的大幅下降。两者结合的“专家探索收集 $\to$ 蒸馏内化沉淀”构成了完整的认知闭环。
