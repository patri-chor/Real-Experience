# 实验计划 P1：反思驱动的经验复用最小原型

## 角色与工作流声明
- **任务发布区**：`task/p1/`（本目录）。存放由架构师（Planner）规划的子任务文件（如 `01_memory.md`）。
- **代码工作区**：`p1/`（外部目录）。所有子智能体编写的源码、脚本和数据均应存放于此。
- **工作流**：
  1. 架构师拆解任务并发布到 `task/p1/`。
  2. 轻量级子智能体（Executor）读取任务文件，在 `p1/` 中编写代码并自测。
  3. 子智能体提交结果，由架构师进行严格的代码验收（验收函数签名、运行正确性、逻辑是否符合论文核心）。

## 架构规划 (位于 `p1/`)
```text
p1/
├── data/                       # 测试数据与生成的轨迹数据
├── scripts/                    # 顶层执行脚本
└── src/
    ├── memory/                 # 阶段一：索引记忆模块
    ├── expert/                 # 阶段二、三：专家模型与工具调用模块
    └── distill/                # 阶段四：轨迹收集与蒸馏模块
```

## 里程碑与任务拆解

### 任务 1：构建简易索引记忆 (01_memory)
- **目标**：在 `p1/src/memory/vector_store.py` 和 `p1/src/memory/data_builder.py` 中实现向量存储与测试数据生成。
- **状态**：已完成 (代码及自测验证通过)

### 任务 2：专家 Agent 与工具调用 (02_expert)
- **目标**：在 `p1/src/expert/` 下实现具有思考与工具调用能力的 `ExperienceExpert` 及 `EXPERT_SYSTEM_PROMPT`。
- **状态**：待分配

### 任务 3：效果验证与轨迹收集 (03_evaluation)
- **目标**：在 `p1/scripts/` 中串联记忆模块与专家模块，完成“简单/相似/无关”题的测试及轨迹收集。
- **状态**：待分配

### 任务 4：小模型微调与内化测试 (04_distill)
- **目标**：在 `p1/src/distill/` 中实现 SFT 微调脚本和去掉提示词后的内化能力验收逻辑。
- **状态**：待分配
